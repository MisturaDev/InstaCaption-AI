# InstaCaption AI

AI-powered Instagram caption generator that helps you create engaging captions based on your content, style, tone, and language.

---

## Features

- Generate Instagram captions with AI
- Choose different caption styles and tones
- Generate multiple caption variations
- Generate relevant hashtags
- Support for multiple languages
- Copy captions with ease
- Clean and responsive interface

## Getting Started

### Prerequisites

- Node.js
- Google Gemini API key

### Installation

```bash
git clone https://github.com/MisturaDev/InstaCaption-AI.git
cd InstaCaption-AI
npm install
```

### Environment Variables

Create a .env.local file in the project root:
```bash
GEMINI_API_KEY=your_gemini_api_key
```

### Run Locally

```bash
npm run dev
```
